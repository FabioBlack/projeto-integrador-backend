# API Faculdade

Projeto Integrador – Fase 2  
Curso: Análise e Desenvolvimento de Sistemas  
Instituição: Faculdade Gran  

API REST desenvolvida em Node.js utilizando o framework NestJS, com persistência de dados via TypeORM e banco de dados SQLite.  
O projeto implementa um CRUD completo para gerenciamento de Produtos, Fornecedores e Associações, seguindo os princípios de arquitetura REST.

---

## 🚀 Tecnologias Utilizadas

- Node.js
- NestJS
- TypeORM
- SQLite
- Class-validator
- Swagger
- Insomnia
- Git/GitHub
